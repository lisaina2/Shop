Shop — интернет-магазин на Django
Проект представляет собой веб-приложение для онлайн-торговли с аутентификацией пользователей, корзиной и системой заказов. Разработан с использованием фреймворка Django (Python).

Установка
Клонируйте репозиторий:

git clone https://github.com/lisaina2/Shop.git

Перейдите в директорию проекта:

cd Shop

Создайте и активируйте виртуальное окружение:

python -m venv .venv ..venv\Scripts\activate # Для Windows source .venv/bin/activate # Для macOS/Linux

Установите зависимости:

pip install -r shop/requirements.txt

Настройте параметры в shop/settings.py (например, SECRET_KEY, базу данных).

Примените миграции:

python shop/manage.py migrate

Запустите сервер разработки:

python shop/manage.py runserver

Откройте в браузере http://127.0.0.1:8000/ — сайт запущен!

Структура проекта
shop/

├── accounts/ # Аутентификация и профили пользователей

├── cart/ # Корзина и управление товарами в корзине

├── orders/ # Обработка заказов и их статусов

├── shop/ # Основные настройки Django (settings, urls, models)

├── static/ # Статические файлы (CSS, JS, изображения)

├── templates/ # HTML-шаблоны для страниц

├── manage.py # Точка входа для управления проектом

└── requirements.txt # Список зависимостей

Функциональность
Аутентификация: регистрация, вход, выход, восстановление пароля.

Корзина: добавление/удаление товаров, расчёт итоговой суммы.

Заказы: оформление, отслеживание статуса, история заказов.

Админ-панель: управление товарами, категориями, пользователями.

Статическая вёрстка: базовые стили CSS, адаптивный дизайн.


Используемые технологии

Django — веб-фреймворк на Python.

Python 3.8+ — язык программирования.

SQLite (по умолчанию) / PostgreSQL (рекомендуется для прода).

HTML/CSS/JavaScript — фронтенд.


Git/GitHub — контроль версий.


Полезные команды

Запустить сервер: python shop/manage.py runserver

Создать суперпользователя: python shop/manage.py createsuperuser

Применить миграции: python shop/manage.py migrate

Собрать статику: python shop/manage.py collectstatic

Запустить тесты: python shop/manage.py test
